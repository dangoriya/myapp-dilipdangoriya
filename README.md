# Simple Fullstack App — Next.js

## Quick Start (Docker)

```bash
# 1. Clone
git clone https://github.com/dangoriya/myapp-dilipdangoriya.git
cd myapp-dilipdangoriya

# 2. Run with Docker Compose
docker compose up --build -d

# Frontend Access → http://localhost:8080
```
